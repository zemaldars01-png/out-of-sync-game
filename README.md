# Out of Sync

Out of Sync is my first Godot game. It is a glitch-themed escape game where the player has to complete different challenges and escape each level.

In the first level, the goal is to collect all 5 keys before the timer runs out and then reach the exit. In the second level, the player has to move through a laser room, activate 3 switches, and unlock the final exit.

I also added character selection, restart functionality, timers, collisions, locked and unlocked doors, level transitions, and a final completion screen.

This project helped me learn a lot about Godot, especially working with scenes, scripts, signals, collisions, and debugging. I ran into a lot of small problems while building it, but fixing them helped me understand the engine much better.
