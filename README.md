# Out of Sync 🎮

Out of Sync is my first game that I made using Godot. It's a small escape game where you have to collect items, avoid obstacles and complete challenges to get out of different rooms.

I wanted to try making a game because I had never used Godot before. I didn't know much about game development when I started, so most of the things I learned while working on this project.

## Play My Game

You can play it here:
https://zemal-dars.itch.io/out-of-sync

## About the Game

The game has a glitch-style theme. When you start, you can choose between a boy and a girl character.

There are two levels in the game.

In the first level, you have to collect 5 keys before the timer runs out. Once you collect all the keys, the door unlocks and you can move to the next room.

The second level is a laser room. There are 3 lasers that you need to avoid while moving around. You have to activate 3 switches to turn off the lasers and unlock the exit door.

After completing both levels, you reach the ending screen.

## Game Features

I added a starting screen where you can choose your character before playing. The game also has player movement, a timer, collectible keys and doors that unlock after completing the tasks.

For the second level, I added lasers, switches and collision detection. I also made a restart option so players can try again if they fail.

I tried to keep the game simple because this was my first time making something like this.

## How I Made It

I made this game using Godot Engine and GDScript. I also used Canva for some of the backgrounds and images.

I started with the main menu and character selection. After that, I worked on making the player move and added the first level.

At first, I only had a room and a character that could move around. Then I slowly added the keys, timer and exit door.

Once the first level was working, I started making the laser room. This part was a little more difficult because I had to connect the switches with the lasers and make sure the door only opened after completing everything.

I kept testing the game while making changes. Sometimes I had to watch tutorials or try different things to understand how something worked.

## Problems I Faced

I had quite a few problems while making the game, especially with the lasers.

One of the lasers wasn't disappearing when I activated its switch. I also had some problems with collision detection because the player wasn't always reacting to the lasers correctly.

Another issue was the timer. At one point, it was showing two different numbers instead of working normally. I also had to fix the restart button and some problems with changing levels.

I spent a lot of time testing things and checking my code. Sometimes I fixed one problem and another one appeared, which was honestly a little annoying.

But slowly I managed to fix the issues and get the game working.

## What I Learned

I learned quite a lot from this project because I was completely new to Godot.

I learned how scenes work, how to write basic GDScript, how to move characters and how to use signals to connect different things in the game.

I also got a better idea of how timers, collisions and changing scenes work.

The biggest thing I learned was that even a small game can take a lot of time, especially when you're learning everything for the first time.

## Tools I Used

I mainly used Godot Engine to build the game and GDScript for the coding. I used Canva for some of the visuals, GitHub to keep my project files and itch.io to publish the finished game.
